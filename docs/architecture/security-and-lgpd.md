# Segurança e LGPD

## Princípios

- Privacy by design;
- Security by design;
- Menor privilégio;
- Minimização de dados;
- Segregação de usuários;
- Rastreabilidade;
- Retenção controlada;
- Transparência.

## Controles obrigatórios

- Criptografia em trânsito;
- Criptografia em repouso quando suportada pela infraestrutura;
- Controle de sessão;
- Rate limiting;
- Validação de entrada;
- Proteção contra acesso horizontal indevido;
- Logs de auditoria;
- Backups;
- Monitoramento;
- Segregação de ambientes;
- Dados mascarados em ambiente de teste;
- URLs temporárias para documentos;
- Verificação de tipo e tamanho de arquivo;
- Processamento seguro de PDFs e planilhas.

## Plano compartilhado

O titular pagante nunca recebe autorização implícita sobre dados de membros.

A relação de cobrança é distinta da propriedade dos dados.

## Documentos financeiros

- Armazenamento privado;
- Acesso apenas ao proprietário e a processos internos autorizados;
- Não expor URL pública;
- Registrar acesso relevante;
- Não usar documentos para treinamento de IA sem base legal aplicável;
- Definir política de retenção e exclusão.

## Incidentes

O sistema deve evoluir para possuir:

- Processo de identificação;
- Contenção;
- Investigação;
- Comunicação;
- Recuperação;
- Registro pós-incidente;
- Revisão de controles.
