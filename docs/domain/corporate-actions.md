# Eventos Corporativos

## Prioridade inicial

1. Split;
2. Grupamento;
3. Bonificação;
4. Dividendos;
5. JCP.

## Regras fundamentais

- Evento deve possuir ativo, data de referência, fator e fonte;
- A regra aplicada deve ser auditável;
- Quantidade antes e depois deve ser exibível;
- Custo econômico total deve ser preservado quando aplicável;
- Frações devem ser identificadas;
- Reprocessamento deve ser idempotente;
- Usuário deve poder entender o efeito do evento na carteira.

## Não assumir

- Que todo evento corporativo segue a mesma regra;
- Que ticker é imutável;
- Que bonificação, split e subscrição têm o mesmo efeito;
- Que dados de fonte externa são perfeitos.
