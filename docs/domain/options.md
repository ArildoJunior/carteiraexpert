# Opções

## Finalidade

Organizar posições e alertar sobre datas relevantes.

## Campos básicos

- Ativo-objeto;
- Tipo: CALL ou PUT;
- Código;
- Strike;
- Vencimento;
- Prêmio;
- Quantidade;
- Data de abertura;
- Status;
- Observações.

## Alertas

- Vencimento próximo;
- Data de exercício;
- Status pendente;
- Lembrete de revisão.

## Aviso obrigatório

A plataforma organiza e alerta.
Não recomenda estratégias, não executa rolagens e não envia ordens.
