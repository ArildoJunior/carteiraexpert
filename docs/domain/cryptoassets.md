# Criptoativos

## Ativos iniciais

- BTC;
- ETH.

## Tipos de evento iniciais

- BUY;
- SELL;
- TRANSFER_IN;
- TRANSFER_OUT;
- NETWORK_FEE;
- MANUAL_ADJUSTMENT.

## Regras

- Quantidades exigem alta precisão;
- Transferência entre carteiras do mesmo usuário não representa venda;
- Taxa de rede deve ser registrada separadamente;
- Exchange e carteira de autocustódia devem ser identificáveis;
- Dados de cotação possuem fonte e horário;
- Não há execução, recomendação ou conexão automática com exchange no MVP.
