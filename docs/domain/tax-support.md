# Apoio Tributário

## Finalidade

Organizar dados e indicar possíveis pontos de atenção tributária.

## Limites

- Não emite DARF;
- Não efetua pagamento;
- Não substitui contador;
- Não afirma obrigação definitiva quando dados podem estar incompletos;
- Não deve ocultar limitações.

## Recursos futuros

- Resultado mensal;
- Lucros e prejuízos;
- Compensações;
- Alertas;
- Relatório anual;
- Exportação para contador;
- Regras versionadas;
- Histórico de cálculo.

## Aviso padrão

Com base nos dados cadastrados e nas regras parametrizadas, pode haver indícios
de obrigação tributária no período. Valide os dados e consulte profissional
habilitado antes de tomar decisões ou realizar pagamentos.
