# Dados de Mercado

## Princípios

- Dados consumidos pelo usuário vêm do banco interno;
- Toda cotação deve possuir ativo, moeda, fonte e data/hora;
- Defasagem deve ser comunicada;
- Provedores são adaptadores substituíveis;
- Dados gratuitos devem ser usados apenas quando legalmente permitidos;
- A fonte não deve ser exposta como garantia de tempo real.

## Tipos iniciais

- Cotação;
- Histórico diário;
- Câmbio;
- Metadados de ativo;
- Bolsa;
- Moeda.

## Não objetivos iniciais

- Streaming em tempo real;
- Livro de ofertas;
- Execução;
- Profundidade de mercado.
