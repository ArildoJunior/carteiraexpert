# Escopo do MVP

## Objetivo do MVP

Entregar uma base confiável de consolidação patrimonial com carteira individual,
operações manuais, cálculo de posição e custo médio, privacidade, auditoria,
dados de mercado com atraso explícito e eventos corporativos iniciais.

## Incluído no MVP

- Cadastro, autenticação e perfil;
- Aceite de termos e avisos obrigatórios;
- Carteiras individuais;
- Cadastro manual de compras e vendas;
- Taxas operacionais;
- Histórico de operações;
- Cálculo de posição e custo médio;
- Dashboard básico;
- Eventos corporativos iniciais:
  - split;
  - grupamento;
  - bonificação;
  - dividendos;
  - JCP;
- Dados de mercado internos com atraso informado;
- Gráficos básicos configuráveis;
- Plano Free;
- Estrutura de entitlements para Premium;
- Auditoria de alterações críticas;
- Importação por CSV/XLSX em etapa posterior do MVP;
- Base para ativos internacionais e criptoativos.

## Não incluído no MVP inicial

- Integração direta com corretoras;
- Execução de ordens;
- Emissão ou pagamento de DARF;
- Recomendação de compra, venda ou estratégia;
- Chat de IA para usuário final;
- IA autônoma publicando conteúdo;
- Processamento completo de PDFs de todas as corretoras;
- Cobertura completa de todos os tipos de eventos corporativos;
- Cobertura de todos os mercados e exchanges;
- Aplicativo mobile nativo.
