# Planos e Entitlements

## Conceitos

- Plano: conjunto comercial de recursos.
- Entitlement: permissão técnica que habilita ou bloqueia um recurso.
- Assinatura: vínculo de pagamento associado a um plano.
- Grupo compartilhado: grupo de benefícios Premium associado a uma assinatura.
- Titular pagante: usuário responsável pelo pagamento e gestão de convites.
- Membro: usuário beneficiado pelo grupo compartilhado.

## Plano Free

Recursos iniciais:

- Carteira individual;
- Lançamentos manuais;
- Visualização de posição;
- Histórico básico;
- Dashboard básico;
- Dados de mercado com atraso informado;
- Gráficos básicos;
- Recursos limitados de projeção, conforme regras futuras;
- Uso normal após downgrade de um plano pago.

## Plano Premium Individual

Recursos previstos:

- Limites ampliados;
- Importações avançadas;
- Projeções avançadas;
- Área de opções;
- Alertas avançados;
- Relatórios ampliados;
- Área tributária avançada;
- Conteúdo editorial Premium;
- Maior capacidade documental.

## Plano Compartilhado

- Uma assinatura paga por um titular;
- De 3 a 5 membros, conforme regra comercial definida;
- Cada membro possui conta própria;
- Cada membro possui carteira, documentos, alertas, estudos e relatórios próprios;
- O titular gerencia pagamento e convites;
- O titular não acessa dados financeiros dos membros.

## Inadimplência ou cancelamento

Quando a assinatura compartilhada perder validade:

1. O grupo deixa de fornecer entitlements Premium;
2. Todos os membros passam para o Plano Free;
3. Dados existentes não são apagados;
4. Recursos Premium ficam bloqueados;
5. Cada membro continua podendo usar os recursos Free;
6. O titular também passa ao plano correspondente à sua situação de assinatura.

## Regra de segurança

A associação de um usuário a um grupo compartilhado concede apenas benefícios de plano.
Ela nunca concede leitura, edição ou exportação de dados de outro usuário.
