# Solicitação de Revisão Independente para IA

Atue como revisor técnico, de segurança, privacidade e regras financeiras.

Não reescreva código nesta etapa.

Avalie a implementação considerando:

- Escopo aprovado;
- Contexto permanente;
- Regras de desenvolvimento;
- ADRs relacionados;
- Isolamento entre usuários;
- Privacidade do plano compartilhado;
- Uso de Decimal;
- Auditoria;
- Idempotência de jobs;
- Validação com Zod;
- Regressões;
- Testes.

Classifique cada problema como:

- Crítico;
- Alto;
- Médio;
- Baixo;
- Melhoria opcional.

Para cada item informe:

1. Arquivo;
2. Problema;
3. Impacto;
4. Correção sugerida;
5. Necessidade de teste adicional.

Ao final, apresente:

- Itens bloqueadores;
- Itens recomendados antes do merge;
- Itens que podem ser tratados posteriormente.
